QUICK SETUP

URP: Just drag and drop any HDRI materials you want onto the sky. That’s it.

HDRP: In the Global Volume, set the Sky Type to HDRI Sky and add the HDRI Sky component.




NOTES

- HDRI files can be used in all versions of Unity and even in all game engines.

- HDRI files work in 32-bit, meaning they have a high dynamic range. Therefore, you should use tone maps such as ACES, AgX, or Filmic. Otherwise, color clipping or overexposure may occur.

- HDRI files are set to 4K by default. However, you can lower the resolution depending on the situation. 4K–8K is recommended for consoles, 2K–4K for PC, and 1K for mobile devices.
